# 今天要吃什麼？

一個以瀏覽器即可執行的每日選餐轉盤網站。

## 功能

- 依餐點分類篩選轉盤選項
- 轉盤動畫隨機選餐
- 新增、刪除餐點
- 管理後台：查看統計、搜尋、編輯與刪除餐點
- 管理員登入／登出權限
- 每個餐點分類新增 50 道選項，另有 50 道飲料
- 依目前台灣外食常見消費區間估算價格級距
- 飲料可選甜度與冰塊等級，偏好會記住
- 餐點可加入購物車、調整數量並提交到店付款訂單
- 結帳收集姓名、電話與備註
- 使用 IndexedDB 持久化儲存餐點資料（資料存在使用者自己的瀏覽器中）
- RWD 手機版面

## 開始使用

直接用瀏覽器開啟 `index.html` 即可。首次開啟會自動建立資料庫並加入 12 筆示範餐點。

首頁下方的「餐點管理後台」可新增、編輯、搜尋與刪除餐點。預設展示帳號為 `admin`，密碼為 `eat1234`。網站更新後，舊使用者的 IndexedDB 會自動補入新菜單，不會刪除原有資料。

目前登入是前端展示用的 sessionStorage 權限；若要正式部署到公開網站，建議改接後端登入（例如 Supabase Auth、Firebase Auth 或自建 API），避免帳密出現在前端程式碼中。

若瀏覽器限制 `file://` 的 IndexedDB，請用任何靜態檔案伺服器開啟此資料夾；網站本身不需要編譯或安裝依賴。
